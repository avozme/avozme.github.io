# 6. Microservicios con Python y FastAPI
{: .no_toc }

- TOC
{:toc}

El objetivo de este tema es introducirte la **creación de APIs REST ligeras**, de alto rendimiento y preparadas para arquitecturas de **microservicios**. Y, claro, comprender la diferencia entre **microservicios** y **servicios**.

Una de las plataformas más utilizadas en la actualidad para microservicios es **FastAPI**, que está basada en lenguaje **Python**. Por lo tanto, en este tema no solo varemos qué es un microservicio y cómo se monta, sino que tendremos que aprender un poco de **lenguaje Python**, que nunca viene mal.
