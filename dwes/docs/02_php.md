# 2. PHP como lenguaje de servidor

{:toc}

En este capítulo te voy a presentar a un amigo íntimo: **el lenguaje PHP**. 

No vamos a detenernos mucho en la sintaxis básica de este lenguaje, pues es muy parecida a Java, pero sí en qué diferencias tiene con Java y cómo trabaja **en el lado del servidor** para ayudarnos a crear aplicaciones web dinámicas, es decir, aplicaciones que generan un HTML distinto según los datos de entrada y el estado del servidor.

También aprenderemos los fundamentos de las aplicaciones web seguras y cuál es la arquitectura más habitual de las aplicaciones web (llamada MVC = modelo, vista, contolador... ¿Te suena?)

Trabajaremos de forma práctica con algunos **ejemplos de aplicaciones web** sencillas que puedes utilizar como base para tus propios desarrollos. Y, por supuesto, no te escaparás sin desarrollar tu primera aplicación web con PHP en la práctica final de este tema.
