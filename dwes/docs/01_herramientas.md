# 1. Herramientas de desarrollo web

{:toc}

En este tema vamos a sentar las bases del **entorno de trabajo profesional** que utilizaremos a lo largo de todo el curso. Es un entorno totalmente realista, similar al que puedes encontrarte en cualquier empresa del sector (aunque también puedes encontarte muchas otras cosas, claro).

Antes de escribir una sola línea de código en el servidor, es imprescindible **dominar las herramientas** que garantizan la *trazabilidad, la portabilidad y la eficiencia* en el desarrollo web moderno, alejándonos de entornos locales rígidos y de malas prácticas de gestión de código.

No hablamos de usar un editor de texto de forma eficaz: eso ya suponemos que sabes hacerlo. Puedes usar tu editor preferido para escribir PHP, Python o el lenguaje que toque en ese momento. Eso no es relevante.

Las herramientas de las que hablamos son otras más específicas:

* **Control de versiones** con **Git y GitHub/GitLab**. Aprender a usar eficientemente Git es una habilidad ineludible para cualquiera que quiera dedicarse a la programación profesionalmente.
* **Contenarización con Docker**: Tienes que aprender los suficiente de Docker para ser capaz de **aislar tus servicios** (como PHP, Python o MySQL) en contenedores fácilmente portables en lugar de trabajar en un entorno local rígido.
* **Inteligencia Artificial**: Es imprescindible que aprendas a usarla como un asistente activo para la refactorización, creación de pruebas automatizadas y la generación más rápida de soluciones, de forma que te ayude en tu aprendizaje en lugar de entorpecerlo. Estableceremos para ello un protocolo de entregas que valide el uso ético y la comprensión real del código desarrollado.
