## 2.2. Instalación de Laravel
{: .no_toc }

- TOC
{:toc}

En esta sección vamos a describir el proceso de instalación de Laravel en un servidor local para desarrollo. 

Tienes dos posibilidades:

1. **Usar composer**.
2. **Usar sail**. 

En ambos casos, se trata de mecanismos oficiales de instalación recomendados por Laravel, así que puedes optar por el que quieras. Aunque, por supuesto, siempre eres libre de instalarlo manualmente y por tu cuenta sobre un servidor Apache, nginx o similar.

### 2.2.1. Instalación con Docker (Sail)

**Sail** es una interfaz de línea de comandos ligera para interactuar con el entorno de desarrollo Docker predeterminado de Laravel.

* **PASO 1. Instala Docker**. Asegúrate de que Docker Desktop (Windows/Mac) o el motor de Docker (Linux) estén funcionando.
* **PASO 2. Crea el proyecto**:
  ```bash
  $ curl -s https://laravel.build/mi-app | bash
  ```
* **PASO 3. Levanta el entorno**:
  ```bash
  $ cd mi-app
  $ ./vendor/bin/sail up -d
  ```
* **PASO 4. Base de datos**: Por defecto, en Laravel 12, si no especificas nada, Sail podría usar **SQLite**. Si prefieres MySQL o MariaDB, puedes indicarlo al crear el proyecto o configurarlo en el archivo `.env`.

### 2.2.2. Instalación localizada con Composer

Si prefieres no usar Docker, puedes instalar Laravel directamente en tu sistema usando Composer.

* **PASO 1. Requisitos**: Necesitas PHP 8.2+ y Composer instalados.
* **PASO 2. Crear proyecto**:
  ```bash
  $ composer create-project laravel/laravel mi-app
  ```
* **PASO 3. El servidor de desarrollo**:
  ```bash
  $ cd mi-app
  $ php artisan serve
  ```
* **PASO 4. Base de datos SQLite (Predeterminada)**: A diferencia de versiones antiguas, Laravel 12 viene configurado para usar **SQLite** de forma predeterminada. Verás un archivo llamado `database/database.sqlite`. No necesitas instalar MySQL para empezar a programar.

* **PASO 5. Comprobación**: Visita [http://localhost:8000](http://localhost:8000).
